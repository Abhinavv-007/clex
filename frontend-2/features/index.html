Privacy Architecture

Zero Knowledge by Design

No File Storage

During P2P and local transfers, files exist only in the sender's and receiver's browsers. Clex's servers never see them.

No Account System

P2P transfers need no login. No email, no password, no profile. Open a link and go. Google auth is only needed for Drive fallback.

Offline Capable

After first load, Clex's preparation tools work without internet. Process files locally, then share when you're back online.
