Section 02

Description of Service

Clex is a browser-based file workspace that provides:

  • File preparation tools (image compression, PDF operations, DOCX to PDF conversion, ZIP bundling)
  • File sharing via direct P2P transfer (WebRTC)
  • File sharing via local network transfer
  • File sharing via Google Drive as a fallback mechanism
  • Vault for encrypted local notes, controlled secret links, and timed Google Drive share links

Most processing happens in your browser. Direct P2P and local transfers are not stored on our servers. Google Drive fallback stores files in your Google account. Vault Cloud Share uses temporary Drive sessions with explicit size, quota, and retention limits.

Section 06

Vault Cloud Share Terms

Cloud Share is a timed Google Drive handoff feature and is subject to operational limits:

  • Google Drive sign-in is required to upload and manage Vault Drive sessions
  • Each uploaded file is limited to 1 GB
  • Each connected account is limited to 10 GB of Vault Drive uploads per day
  • Vault Drive sessions are scheduled for deletion after 24 hours
  • Anyone with the Vault link or access code may open the file or folder until the session expires or is deleted

Vault Drive sharing is intended for temporary handoff, not archival use or guaranteed long-term storage.
